# Contributing

Contributions are welcome. The collection is curated so that it remains a scientific reference rather than an unreviewed list.

You can:
1. propose a theoretical mechanics problem;
2. correct an existing entry or add a missing reference;
3. report progress, a counterexample, or a resolved special case;
4. give general feedback on the initiative.

A useful proposal explains why the problem matters mechanically, gives a mathematical form when possible, identifies the strongest known results, and states what would count as meaningful progress or settlement.

Prefer primary sources. An unsuccessful search is not evidence that a problem is open.

AI-assisted submissions are welcome, but a human contributor must understand and take responsibility for the statement, sources, calculations, and claimed status.
