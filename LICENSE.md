This includes the curated problem statements, explanatory prose, canonical problem records, editorial material, progress summaries, and the scientific text rendered in the website.

See `licenses/CC-BY-NC-ND-4.0.txt` for the full license text.

## Website and maintenance code

The software implementation is licensed under the **MIT License**.

This includes scripts, GitHub Actions configuration, issue-template mechanics, and the HTML/CSS/JavaScript implementation of the site. Where a file such as `docs/index.html` contains both scientific prose and software markup, the prose remains under CC BY-NC-ND 4.0 while the implementation code is under MIT.

See `licenses/MIT.txt` for the full license text.
